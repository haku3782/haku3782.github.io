Garden Care Tracker

家庭菜園の記録と可視化 가정 텃밭 기록과 시각화 Plant care tracking and visualization

バックエンドの設計に力を入れた作品です。認可はサービス層でリソースの所有権を検証し、レスポンスはDTOを経由させて内部フィールドを隠し、ファイルはサーバー経由でプロキシしてストレージの秘密鍵をクライアントに渡さない。

백엔드 설계에 공을 들인 작품입니다. 인가는 서비스 레이어에서 리소스 소유권을 검증하고, 응답은 DTO를 경유시켜 내부 필드를 숨기며, 파일은 서버 경유로 프록시하여 스토리지 시크릿 키를 클라이언트에 전달하지 않습니다.

The focus of this project is backend design. Authorization is verified at the service layer against resource ownership; responses go through DTOs so internal fields can never leak; file uploads are proxied through the server so the storage secret never reaches the client.

Darts Physics Simulator

セッティングから飛翔軌道を計算する 세팅으로부터 비행 궤도를 계산하는 Trajectory simulation from equipment setup

物理エンジンで計算した軌道をThree.jsで3D再生する構成です。バックエンドがPOSTひとつで全軌道をバッチ返却し、フロントエンドがその配列をそのまま描画する。物理モデルは迎角依存の抗力と姿勢ダイナミクスを実装し、対象外の範囲もドキュメントに明記しました。

물리 엔진으로 계산한 궤도를 Three.js로 3D 재생하는 구성입니다. 백엔드가 POST 한 번으로 전체 궤도를 배치 반환하고, 프론트엔드가 그 배열을 그대로 렌더링합니다. 물리 모델은 받음각 의존 항력과 자세 다이나믹스를 구현하고, 대상 외 범위도 문서에 명기했습니다.

The backend computes the full trajectory and returns it in a single POST response; the frontend hands the array directly to Three.js for 3D playback. The physics model implements angle-of-attack-dependent drag and pitch attitude dynamics, and everything left out of scope is documented explicitly.
